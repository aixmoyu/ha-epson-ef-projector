# ha-epson-ef-projector

爱普生 EF 系列投影仪没有 PJLink，没有 ESC/VP21，也没有可用的网页管理界面。它直接使用投影仪固件自带的一个 HTTP 控制接口，把这台设备完整接进了 Home Assistant。

整个过程只发生在局域网内。不需要厂商云服务，不需要在投影仪上开启 USB 调试或网络调试，不需要 ADB，也不依赖任何会随固件升级而失效的临时手段。

## 实体与能力

**开关机与播放控制**
开机、关机，按固件的实际状态判断后再动作，重复调用不会误翻转。音量加减、静音、播放、暂停、上一个、下一个。静音没有状态查询，因此由 Home Assistant 侧记忆，重启后可恢复。

**画面参数**
光源亮度（50–100，与机身滑条同范围）、投影方式（正投／吊装／背投／吊装背投）、投影偏好（色彩／明亮）、色温、动态对比度、红绿蓝三路增益（0–255），以及启动模式（节能／快速启动）。

所有可读参数的固件原始值都以 `raw_value` 属性暴露，便于与机身菜单逐项对照。

**对焦与光学**
对焦位置（0–264，闭环定位）、刷新定时器（1–24 小时）、自动对焦触发、测试图案。

**几何校正**
画面放大／缩小、四向位移、重置全部校正。变焦与位移的步进量取自真机实测，往返操作可精确回到基线。

**氛围灯**
开关、亮度、光效模式。这类能力固件只提供写入、不提供读取，因此实体状态标记为假设值（`assumed_state`），并在重启后恢复最后已知值，而不是伪装成真实读数。

**诊断与信息**
灯光累计时长（待机时保留上次读数，并以 `stale` 与 `measured_at` 标明新鲜度）、投射距离、在线状态、固件版本与若干硬件标识属性。

**服务**
`epson_ef.send_key` 发送任意遥控器按键；`epson_ef.raw_request` 透传任意固件命令，结果通过事件返回，供排障与实验使用。

## 兼容性

已在 EF-50 上完整验证。

同一固件平台的其他爱普生智能投影型号理论可用——添加集成时会先做一次连通性校验，通过即可使用。不具备该 HTTP 服务的传统爱普生机型不适用，那类设备请使用官方集成或 PJLink。

## 安装

### HACS（推荐）

在 HACS 中用「自定义存储库」添加 `https://github.com/aixmoyu/ha-epson-ef-projector`，类别选择「集成」，安装后重启 Home Assistant。

### 手动部署

要求 Home Assistant 2024.4 或更新版本。

```bash
rsync -av custom_components/epson_ef/ \
  <user>@<ha主机>:<ha配置目录>/custom_components/epson_ef/
# 然后重启 Home Assistant 容器
```

### 添加设备

设置 → 设备与服务 → 添加集成 → Epson EF Projector，填入投影仪的局域网 IP。端口保持默认 8080，名称可自定义。

## 已知限制

- 音量只能步进调节，固件不提供当前音量级查询。
- 静音是切换语义且无状态反馈。用实体遥控操作后，Home Assistant 显示的状态可能与之不一致。
- 启动模式的中文选项与固件 0/1 原始值的对应关系来自固件菜单定义，未逐台核对；如遇相反情况，可查看 `raw_value` 属性确认。
- 待机（熄屏）状态下灯光时长查询会失败——这正是判断开关机的依据，同时也意味着该传感器只在唤醒时更新。
- 路由器的 DHCP 续租失败会导致待机中的设备主动断开 Wi-Fi（日志特征 `reason=3 DEAUTH_LEAVING, locallyGenerated`），表现为实体不可用。建议为投影仪做静态地址绑定并延长租约。
- 整机断电时无法远程唤醒，这是网络物理中断导致的硬件限制，遥控器是最终手段。
- 投影仪 IP 变化后，请使用集成详情页的「重新配置」更新地址。

## 安全

投影仪固件内置的认证凭据是同平台机型通用的常量，本仓库的代码中包含该值。这并非本项目引入的漏洞——任何持有该设备的人都能提取出来——但也意味着，能访问 8080 端口的人就能控制这台投影仪。请勿将该端口映射到公网。

`raw_request` 服务可以发送任意固件命令，建议仅在管理员可用的场景下使用，并配合 Home Assistant 自身的用户权限控制。
